## Readest 安卓端使用指南（自建服务器版）

本文档基于当前 Docker 部署的服务端环境，说明如何在安卓设备上安装和配置 Readest APK。

---

### 前置条件

安卓设备必须能够访问服务器 IP `100.108.143.105`。该地址为 Tailscale 内网 IP，因此安卓设备需要加入同一 Tailscale 网络。安装 Tailscale 客户端并登录后即可自动加入网络，无需额外配置。

如果服务器部署在局域网内，请确保手机与服务器在同一 Wi-Fi 下。

---

### 第一步：安装 APK

将 `Readest-arm64-*.apk` 传输到安卓设备并安装。支持 arm64 架构的安卓 7.0（API 24）及以上设备。

安装方式不限：USB 传输、微信/QQ 发送、网盘下载、ADB install 均可。如果系统提示"未知来源应用"，需在设置中允许安装。

---

### 第二步：首次启动 — 服务器配置

首次打开应用会看到 **Self-hosted Server Setup / 自建服务器配置** 向导页面，需要填写两项：

**Server URL（必填）**

填写 Kong 网关的完整地址：

```
http://100.108.143.105:8000
```

这是安卓端与服务端通信的唯一入口。Kong 网关会将认证、数据库查询、文件存储等请求分发到后端各服务。不要填写 3000 端口（那是 Web 前端页面端口），也不要填写 9000/9002 端口（那是 MinIO 文件存储端口）。

> **提示：** 配置向导只需要填写 **一个地址**——Kong 网关 URL。无需分别配置认证、数据库、文件存储等各服务的地址，Kong 会自动按请求路径将流量转发到正确的后端服务。

**Anon Key（必填）**

粘贴以下 JWT 令牌：

```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJyb2xlIjoiYW5vbiJ9.6Nl5poEhCBJiTUHLdCNNQcSbNN10lCKN45Wd3iSkLbo
```

这是 Supabase 的匿名访问密钥（Anon Key），用于客户端身份验证。虽然向导标注为 "optional"，但由于我们的构建没有内置默认密钥，这里必须填写。此密钥仅具有受限的数据库访问权限（由 PostgreSQL RLS 策略控制），不会暴露管理员权限。

**点击 Connect / 连接**

向导会向 `http://100.108.143.105:8000/auth/v1/health` 发送探测请求验证连通性。成功后配置会自动保存到本地，后续启动不再显示此页面。

如果连接失败，常见原因包括：Tailscale 未连接、IP 或端口填写错误、服务端 Docker 未运行。

---

### 第三步：注册和登录

配置成功后进入应用主界面。当前服务端配置如下：

- 邮箱注册已开启（`ENABLE_EMAIL_SIGNUP=true`）
- 邮箱自动确认已开启（`ENABLE_EMAIL_AUTOCONFIRM=true`）
- 无需配置 SMTP，注册后直接可用

点击注册，输入任意邮箱和密码即可完成注册并自动登录，无需邮箱验证。

---

### 第四步：使用

登录后即可正常使用全部功能。与服务器相关的功能说明：

**书籍同步与存储**：书籍文件通过 MinIO（S3 兼容存储）上传下载，经由端口 9002 的 Nginx 代理访问。当前配额为 20GB。

**翻译功能**：当前翻译配额为 50,000 次。

**多设备同步**：只要所有设备连接同一服务器（相同的 Server URL + Anon Key），使用同一账号登录即可自动同步书架、阅读进度和笔记。

> **说明：** 此前版本中存在的同步失败和登录会话过期问题已修复。当前版本中，只要 Server URL 正确指向 Kong 网关，书籍上传、下载和多设备同步功能均可稳定工作，登录会话也不会异常过期。

---

### 修改服务器配置

如果需要更换服务器地址，目前需要清除应用数据后重新打开（设置 → 应用 → Readest → 清除数据），向导会再次出现。

---

### 服务端端口速查

| 端口 | 服务 | 客户端是否需要 |
|------|------|--------------|
| 8000 | Kong 网关（API 入口） | **是，填写在 Server URL** |
| 3000 | Web 前端页面 | 否（仅浏览器访问） |
| 9000 | MinIO S3 API | 否（内部调用） |
| 9001 | MinIO 管理控制台 | 否（管理员用） |
| 9002 | Nginx S3 代理 | 否（内部自动调用） |
| 5432 | PostgreSQL 数据库 | 否（内部使用） |

---

### 快速总结

首次启动只需要记住两样东西：服务器地址 `http://100.108.143.105:8000`，和上面那串 Anon Key。填好连接成功后，用任意邮箱注册即可开始使用。

---

### 常见问题

**Q：同步失败，书籍无法上传或下载**

请确认 Server URL 填写的是 Kong 网关地址（`http://<服务器IP>:8000`），而不是其他端口。此前版本中存在的 Kong `/api/*` 路由缺失问题已在服务端修复，当前版本同步功能可正常使用。如果问题仍然存在，请联系服务端管理员检查 Kong 网关配置。

**Q：登录过一段时间后失效，需要重新登录**

此问题已在最新版本中修复。之前由于客户端认证监听器在 Supabase 客户端重新初始化后未能正确刷新，导致登录约 1 小时后会话过期。更新到最新版本后，登录会话可正常保持，无需频繁重新登录。

**Q：连接服务器失败**

常见原因：
- Tailscale 未连接（如果使用 Tailscale 内网 IP）
- 手机与服务器不在同一网络
- Server URL 填写有误（注意端口号应为 8000）
- 服务端 Docker 容器未运行
